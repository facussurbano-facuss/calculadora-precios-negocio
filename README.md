# Calculadora de Precios para tu Negocio

- el **precio de venta** que cubre mercadería, gastos fijos y comisiones,
- tu **ganancia real** por unidad y por mes,
- cuántas ventas necesitás por mes **para no perder plata** (punto de equilibrio).
